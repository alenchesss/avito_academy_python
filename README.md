# Домашнее задание №3 «Классы»

## Описание

Программа преобразует тексты в числовые векторы, рассчитывает TF-IDF и выделяет ключевые слова.

## Требования

- Python 3.9 или выше.
- Дополнительные библиотеки не требуются. Используется стандартная библиотека Python.

## Установка и запуск

1. Клонировать репозиторий:

```bash
git clone https://github.com/alenchesss/avito_academy_python.git
```

2. Перейти в папку проекта:

```bash
cd avito_academy_python
```

3. Запустить программу:

```bash
python hw_classes_base.py
```
