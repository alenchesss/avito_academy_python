# Домашнее задание №2 «Функции»

## Описание

Программа считывает данные сотрудников из CSV-файла и формирует отчёты:

1. Иерархия департаментов и команд.
2. Сводная статистика по численности сотрудников и зарплатам.
3. Сохранение сводной статистики в CSV-файл.

## Требования

- Python 3.9 или выше.
- Дополнительные библиотеки не требуются. Используется стандартная библиотека Python.

## Установка и запуск

1. Клонировать репозиторий:

```bash
git clone https://github.com/alenchesss/avito_academy_python.git
```

2. Перейти в папку проекта:

```bash
cd avito_academy_python
```

3. Запустить программу:

```bash
python main.py
```

После запуска программа предложит выбрать один из трёх вариантов отчёта. Для выбора необходимо ввести соответствующее число от 1 до 3.

Файл `Corp_Summary.csv` должен находиться в рабочей директории программы.

При выборе третьего варианта отчёт сохраняется в файл `information.csv`.
