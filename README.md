# Домашнее задание №1

## Описание

Репозиторий содержит решения пяти задач на Python.


## Требования

- Python 3.8 или выше.
- Дополнительные библиотеки не требуются. Используется стандартная библиотека Python.

## Установка и запуск

1. Клонировать репозиторий:

```bash
git clone https://github.com/alenchesss/avito_academy_python.git
```

2. Перейти в папку проекта:

```bash
cd avito_academy_python
```

3. Запустить нужное задание:

```bash
python task1.py
python task2.py
python task3.py
python task4.py
python task5.py
```

Каждый файл запускается независимо от остальных и выводит результаты вычислений в консоль.
