# Домашнее задание №2 «Функции»

## Описание

Программа формирует отчёты по сотрудникам из файла `Corp_Summary.csv`
1. Иерархия департаментов и команд.
2. Статистика по зарплатам и количеству сотрудников.
3. Сохранение статистики в CSV-файл.

## Требования

- Python 3.9 или выше.
- Дополнительные библиотеки не требуются. Используется стандартная библиотека Python.

## Установка и запуск

1. Клонировать репозиторий:

```bash
git clone https://github.com/alenchesss/avito_academy_python.git
```

2. Перейти в папку проекта:

```bash
cd avito_academy_python
```

3. Запустить программу:

```bash
python main.py
```

Файл `Corp_Summary.csv` должен находиться в рабочей директории программы.

Для выбора отчёта необходимо изменить аргумент функции `main()`:

```python
main(1)  # Иерархия
main(2)  # Статистика
main(3)  # Экспорт в CSV
```

Для третьего варианта можно указать имя выходного файла:

```python
main(3, 'report.csv')
```

По умолчанию отчёт сохраняется в `information.csv`.
